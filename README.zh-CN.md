# Hostile Neural Networks [![](http://cf.way2muchnoise.eu/hostile-neural-networks.svg)](https://www.curseforge.com/minecraft/mc-mods/hostile-neural-networks) [![](http://cf.way2muchnoise.eu/versions/hostile-neural-networks.svg)](https://www.curseforge.com/minecraft/mc-mods/hostile-neural-networks)

[English](README.md) | [简体中文](README.zh-CN.md)

一个 Minecraft Forge 模组：通过击败敌对模拟来产出战利品掉落物。

本模组基于 Deep Mob Learning，适用于 1.16.5 及以上版本。

## 添加自定义数据模型

要添加自定义数据模型，你只需要一个数据包和一些 json 文件。  
可以[浏览仓库](https://github.com/Shadows-of-Fire/Hostile-Neural-Networks/tree/master/src/main/resources/data/hostilenetworks/data_models)查看示例。  
JSON schema 见[此处](./schema)。
